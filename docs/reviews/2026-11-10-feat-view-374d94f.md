## 374d94f 로드 로그
- `LoadStage`에서 `Stopwatch` 하나로 챕터 교체·보드(`session.Load`)·행성 `Fit` 구간과 메모리(Unity 예약, 관리 힙)를 한 줄, 이어서 코루틴이 다음 5프레임 중 가장 느린 프레임을 한 줄. 스테이지 진입마다 2줄·문자열 2개·코루틴 1개 — 매 프레임 비용 없음. `Stopwatch`·`Profiler.GetTotalReservedMemoryLong`·`GC.GetTotalMemory`는 WebGL에서 동작(9장 금지 API 아님).
- Log 스택 트레이스 설정은 ScriptOnly(`m_StackTraceTypes`)라 줄당 비용이 작다. 플레이테스트 로그에 남겨 두어도 된다. 나중에 줄이고 싶으면 `Debug.isDebugBuild`나 `LaunchOptions`로 감싼다.

## ac99750 smoke 보기 UI 숨김(코어 요청)
- smoke(`Board`/`Empty`)일 때만: HUD는 보드 라벨 레이어 밖 그래픽을 끄고(`LateUpdate`, smoke 아니면 bool 하나로 바로 반환), 다른 루트 캔버스는 `Awake` 시점에 끈다. 측정 영역에 HUD 글자가 걸리던 문제(empty 대조 1483)의 원인 제거.
- 메모: `Awake` 뒤에 생기는 캔버스(예: `SceneFader`의 로딩 화면 — 로드가 끝나면 alpha 0)는 끄지 않는다. 측정은 로드 뒤라 문제없다. smoke 숨김 `LateUpdate`의 `GetComponentsInChildren` 할당은 smoke 전용이라 허용.
