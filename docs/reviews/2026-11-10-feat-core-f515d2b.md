# 검토: feat/core f515d2b (board-pixels 캔버스 기준 측정, LockBits)

검토자: 아키텍트, 2026-11-10. 범위: `unity/Tools/board-pixels.ps1` 하나(도구, 게임 코드·계약 변경 없음).

**결론: 승인.** 리드의 build-webgl + smoke-webgl에서 control 0이면 병합.

## 확인
- `-Background`가 있을 때 캔버스 = 배경색(±28) 픽셀의 경계 상자, 측정 영역(30~70%, 33~66%)은 그 안에서 잡는다. 흰 페이지 여백·페이지 HUD가 영역에서 빠진다. Windows 전체 창 스크린샷은 상자 = 창 전체라 기존과 같은 영역.
- 실패를 놓치는 경로가 없다: 보드 없음은 여전히 ~0, `?smoke` 훅 없는 빌드는 배경색이 없어 전체 이미지로 떨어지고 포화 → empty 대조에서 실패(주석에 명시). smoke 모드 UI 숨김(feat/view ac99750)과 함께라 캔버스 안 마젠타 경계가 끊기지 않는다.
- LockBits `Format32bppArgb` → BGRA 순서(`+2`=R, `+1`=G, `+0`=B) 맞음, `UnlockBits` 후 복사본만 읽음, `finally`에서 Dispose.
- 판정 규칙(채널 하나라도 28 초과)은 이전과 같다. `unity.sh` 호출 인자(`-Path -Background`)도 그대로라 호환.
- `[double]` 변환은 PowerShell 캐스트라 문화권(소수점) 영향 없음.

## 메모 (막지 않음)
- 경계 상자를 2픽셀 간격으로 찾아 상자 끝이 1픽셀 어긋날 수 있다. 영역 비율 계산에 무의미한 차이.
