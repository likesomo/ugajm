# 검토: feat/view 0d30f0f (be1b01f 결과 별, 08d1e77 텔레메트리 lang)

검토자: 아키텍트, 2026-11-10. 기준 `origin/7lucky` aba812c ... `origin/feat/view` 0d30f0f. 코드·프리팹 텍스트 검토. EditMode 740/740은 게임플레이/UI 보고(이 작업 공간은 Unity 라이선스 만료로 배치 실행 못 함).

**결론: 승인.** 아래 N1~N4는 다음 작업에서 정리하면 되는 메모이고 합치기를 막지 않는다.

## 확인한 것
- **6.5 계약과 일치**: 별 수는 `GameFlowController`가 `Stars.Of(...)`로 계산(Won에서), 시도가 바뀌면 0으로 초기화(7028a00 메모 반영). `ResultView`는 받은 값만 그린다(규칙 유출 없음). 0 = 패배 또는 최소 몸 정보 없음 → 별 줄 숨김. `BestStars > Stars`일 때만 최고 기록 줄.
- **연출**: 코루틴 하나, `Hide`/다시 `Show`에서 멈춤, `unscaledDeltaTime`, Play 밖에서는 즉시. 매 프레임 할당 없음(코루틴 객체는 표시당 1회). `Validate`가 `stars` 3개·스프라이트 2개를 요구하므로 프리팹 누락은 scene-validate에서 잡힌다.
- **HUD 다음걸음 상자**: `nextStep.transform.parent` = `Hud.prefab`의 `NextStep` 상자(자식 1개, Text)임을 확인. HUD 루트를 끄는 일은 없다.
- **텔레메트리 lang**: 정상 경로는 부트스트랩이 `Localizer`를 텔레메트리보다 먼저 등록(8481e5c)하므로 `Localizer.Current` + `Changed`. 미등록 경로의 대체 규칙 `launch.Language ?? save.Language`는 13.3과 같다. `SettingsChanged`에서 중복 갱신하지 않는다. `TelemetryRunner`는 DDOL이고 `Localizer`도 앱 수명이라 구독 해제가 없어도 누수 아님.
- **아트 패널을 프리팹 변형으로**: `InstantiatePrefab` → `SaveAsPrefabAsset`이면 변형이 된다(공유 `UI/Prefabs` 레이아웃 변경이 스킨에 전달). 패널 판별을 폭 대신 이름 `Panel`로 바꾼 것도 맞다. `RuinsHengeTheme.asset`의 fileID 변경은 변형 루트 id로 바뀐 것이고 guid는 그대로, `languages`/`number`(13.4) 유지, `chapterCard: 0`은 새 필드 기본값. 병합 결과 이상 없음.
- 의존 방향: Editor(Gameplay) → Game.UI, Game → Core(`Stars.Max`). 문제 없음.

## 메모 (막지 않음)
- **N1** `RuinsHengeUiBuilder.Panel`이 `InstantiatePrefab(source)`를 열린 씬에 만든 뒤 지운다. 에디터 메뉴로 돌리면 열린 씬이 더러워짐 표시가 될 수 있다. 배치 전용이면 상관없고, 메뉴로도 쓴다면 `EditorSceneManager.NewPreviewScene()`에 만들거나 실행 후 씬 상태를 안내.
- **N2** 같은 함수가 변형의 모든 `Text`에 `theme.font`(13.4 이전 기본 글꼴)를 덮어쓴다. 결과·설정 패널의 문구가 키로 옮겨질 때(13.7 게임플레이/UI) 런타임에 `UiText.Set`(역할 글꼴)으로 다시 정하므로 문제는 없지만, 그때 이 덮어쓰기를 지워 변형의 오버라이드를 줄인다.
- **N3** `ResultView`·`HudView`에 새 한글 리터럴("최고 기록 별 {0}개" 등)이 늘었다. `LocalizationCheck`가 WARN으로 세고 있고 13.7 순서대로 옮기면 된다. 키를 만들 때 `{0}` 치환 하나로.
- **N4** `nextStep.transform.parent`는 프리팹 구조에 기댄다. 다음에 HUD 필드를 손볼 때 `public GameObject nextStepBox`로 명시하고 `Validate`에 넣으면 구조 변경에 안전하다.
- `ResultStarsBuilder`는 1회용 프리팹 편집 도구로 문서화되어 있다(이후 프리팹이 원본). 다시 돌리면 줄을 교체하므로 안전.
