# 검토: feat/view 01795d3 (새 플레이어 링크 `-newplayer` / `?newplayer=1`, 텔레메트리 큐 playerId)

검토자: 아키텍트, 2026-11-10. 게임플레이/UI 보고: test 757/757(NewPlayerTests 4), WebGL `?level=1&newplayer=1` 로그·주소창 확인. 코드 읽기 검토.

**결론: 승인.** Contracts(`LaunchOptions`, `SaveSystem`) 변경은 11장 형식대로. docs 11장·변경 기록은 아키텍트가 갱신함.

## 확인한 것
- `LaunchOptions.NewPlayer`: 읽기 전용, 명령줄 플래그·URL 값, 잘못된 URL 값은 `Warnings`. 기본 false라 일반 실행 영향 없음.
- `SaveSystem.StartNewPlayer()`: 진행을 새 `ProgressData`로, `playerId` 비움, 둘 다 즉시 저장. 볼륨·동의·언어·`languageChosen` 유지(리드 결정). 새 빌드 진행의 읽기 전용 보호를 이 경우만 푼다 — 진행자가 명시적으로 연 링크이므로 의도로 기록함. 진행 백업 키(11.3.1)는 이전용이라 건드리지 않는 것이 맞다.
- 순서: `Bootstrap`이 저장을 읽은 직후·텔레메트리 생성 전에 `NewPlayerLink.Apply` → 텔레메트리가 새 id를 만들고 `firstTime`. `Bootstrap`은 씬 플로우 파일(한 줄) — 씬 플로우에 알림.
- WebGL 주소창 인자 제거(jslib, 실패하면 경고만). `LaunchOptions`는 이미 읽은 뒤라 순서 문제없음.
- **큐 playerId 수정**(원래 있던 문제): 큐 항목이 기록 시점의 player를 갖고, 배치는 player·session이 같은 것끼리만 묶는다. 저장 줄 `player\tsession\tjson`, 예전 줄(`session\tjson`, JSON은 `{`로 시작)은 현재 플레이어로 읽는다 — session id는 `{`로 시작하지 않으므로 판별이 안전하다. 같은 테스터의 정상 흐름에서는 배치 JSON이 이전과 같다(텔레메트리 골든 영향 없음).

## 메모
- 새 테스터에게 언어 선택 화면이 다시 나오지 않는다(`languageChosen` 유지). 언어를 바꿔 시작하려면 진행자 링크에 `&lang=en`을 같이 붙인다.
- **itch.io 임베드에서는 동작하지 않는다**: itch.io는 페이지 URL 인자를 게임 iframe에 넘기지 않는다. `?newplayer`·`?level`·`?lang` 모두 같은 제약 — 플레이테스트 1은 직접 호스팅 주소로 진행해야 한다(리드·백엔드 확인).
