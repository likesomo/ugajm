# Game Concept: 13 Floors — 행운의 수

> **상태 (2026-11-06): v1 플레이테스트에서 재설계 판정.** "전투가 너무 단순하고, 숫자로 뭘 하는지 모르겠다." `production/playtests/2026-11-06-v1-13floors.md` 참고.

## Core Identity
| 항목 | 내용 |
|---|---|
| Elevator Pitch | 행운의 수를 골라 7층 탑을 오르는 RPG. 층마다 그 숫자를 계속 믿을지(KEEP), 바꿀지(SWITCH) 결정하고, 버린 숫자는 적이 되어 돌아온다. |
| Core Verb | 결정하기 (KEEP / SWITCH), 숫자 관계를 읽고 공격하기 |
| Core Fantasy | 문화와 수학이 정한 운명을 읽고 내 숫자로 세계를 물들이는 것 |
| Unique Hook | 같은 숫자가 서양·동양·수학에서 정반대 의미를 갖는다 (13: 서양 저주 / 수학 행운) |
| Platform | Web (itch.io, HTML5) |
| Estimated Scope | Small (게임잼 48–72시간, 1–2인) |

## 배경 분석 → 메카닉
| 시선 | 핵심 인식 | 게임 규칙 |
|---|---|---|
| 서양 | 7 축복, 13 저주(13일의 금요일), 3 저주(Three on a match) | 대성당 층: 7 축복, 3·13 저주, 합이 7이면 연쇄 |
| 동양 | 8 = 發, 4 = 死, 7월 = 귀신의 달, 삼세판 | 사원 층: 3·8 축복, 7 저주, 적 4는 겁먹음, 합이 8이면 연쇄 |
| 수학 | Ulam lucky number (1,3,7,9,13…), 약수, 몬티 홀 | 미궁 층: 3·7·13 축복, 짝수 숙청. 약수 관계 = 치명타 |

## 결정이 영향을 미치는 4개 층위
1. **전투**: 적의 숫자와 내 숫자의 관계 (약수면 치명타, 합이 길수면 연쇄, 같은 수는 영입, 흉수 적은 겁먹음)
2. **층**: 문화권이 내 숫자를 축복하거나 저주함. 예보 2층
3. **런**: KEEP은 신앙(공격력, 궁극기, 세상에 내 숫자의 배수가 퍼짐). 저주 문화권의 반격도 강해짐. SWITCH는 각인을 남기고, 신앙 2 이상을 버리면 배신당한 숫자가 등장. 최종 보스는 가장 오래 믿은 숫자
4. **엔딩**: 일편단심 / 저주를 이긴 자 / 방랑자 / 사망. 숫자 타임라인 표시

## Pillars
1. **숫자는 세계의 규칙이다**: 고른 숫자를 모든 시스템이 참조한다.
2. **모든 결정에는 흔적이 남는다**: KEEP과 SWITCH 모두 되돌릴 수 없는 결과를 남긴다.
3. **5초 안에 읽힌다**: 관계(치명타/연쇄/영입)는 계산하게 하지 않고 태그로 보여준다.

## Anti-Pillars
- 카드 덱 관리나 인벤토리 같은 복잡한 빌드 시스템을 만들지 않는다 (Pillar 3 침해).
- 운에만 의존하는 판정을 만들지 않는다. 예보와 관계 태그로 항상 판단 근거를 준다.
- 긴 텍스트 스토리를 넣지 않는다 (잼 범위, 번역 부담).

## 밸런스 검증 (tools/sim.mjs, 500판/셀)
| 전략 | 3 | 7 | 8 | 13 |
|---|---|---|---|---|
| 항상 KEEP | 63% | 60% | 20% | 46% |
| 저주마다 SWITCH | 36% | 43% | 61% | 48% |
| 상황 판단 | 63% | 65% | 62% | 60% |
| 무작위 | 14% | 13% | 13% | 13% |

상황을 읽는 전략이 모든 숫자에서 가장 강하고, 어떤 단순 규칙도 지배하지 않는다.

## MVP / 다음 단계
- MVP(현재): 숫자 4종, 7층, 문화권 3종, 전투 관계, 신앙과 궁극기, 제단, 배신 보스, 최종 보스, 엔딩 4종
- 다음: 사운드(타격·잭팟), 숫자 6종 이상, 4층/F층 이벤트, 몬티 홀 문(제단에서 문 하나 공개), 영어 텍스트
- 리스크: 첫 플레이에서 규칙 이해. 실제 사람 플레이테스트 필요 (봇은 타겟 선택이 최적)
