## 공통 제작 규격과 가독성

- 비교 입력은 moss, 8×6, 정면 직교 pitch 50°·yaw 0°이며 보드 윗면은 평면 y=0, 1칸=1m다. 생성 이미지는 카메라 수치·치수를 증명하는 도면이 아니다.
- 밝은 바닥 #DEDAC8, 어두운 줄눈과 외곽 경계, 청회색 낮은 벽, 검은 구멍, 밝은 청색 사선 얼음, 숫자 3 표지 문, 갈색 진흙을 공통 시험 대상으로 넣었다. 색뿐 아니라 높이·공간·패턴·숫자로 구분한다.
- 타일은 정상부에 직접 박고 장식은 보드 바깥 최소 1m 이후에 배치한다. 전면 선돌 금지, 후면 선돌도 투영 영역이 타일과 겹치지 않도록 확인한다. 디딤돌은 작고 낮게 유지한다.
- 생성 그림의 칸수·간격·형제 색에는 일부 변동이 있다. 특히 B 목업은 칸 간격이 달라졌으며, 7행성 썸네일은 격자가 단순화된다. 실제 8×6 배치의 권위는 레벨 데이터이며 이 그림을 그대로 모델링 도면으로 쓰지 않는다.
- 지원 크기는 6×5~12×5, 10×3, 7×7 등이다. 외피 정상부는 보드 bounds에서 사방 1m 완충 후 장식 폭 0.5–1m를 추가해 가변 생성한다. 12×5는 최소 14×7m 정상부를 지지하고 장식은 그 밖으로 옮긴다. A는 긴 암반, B는 장변 모듈 추가, C는 긴 코어와 뿌리 간격 재배치, D는 원을 억지 확대하지 않고 장원형 방사 기단으로 변형한다.

## HUD 목업

기존 `concepts/ui/en/hud.png`의 남색 면·놋쇠 이중 테두리·크림 손글씨·금색 숫자와 칠성 표시를 참조했다. 원본 인게임 HUD도 읽고 상단 제목/칠성/형제 상태, 좌측 도움말, 하단 5버튼을 분리했다. 4개 목업은 동일한 레이아웃이다. 1280×720으로 크기만 정규화했으며 실제 게임 UI 캡처를 변경한 결과가 아니다.

목업 시각 검토상 텍스트와 장식, HUD와 보드의 겹침은 없다. 구현 안전 영역 제안은 상단 y=0–128, 좌측 x=0–304, 하단 y=620–720, 게임 영역 x=328–1256/y=144–604다. 배경 섬까지 게임 영역 내부에 맞추고 영역 사이 최소 16px를 둔다. 12×5에서는 보드와 외피 전체 bounds를 투영해 맞추고 UI를 이동시키지 않는다. 긴 보드의 글자 최소 크기와 7×7 세로 범위는 2단계에서 실 카메라로 검증해야 한다. 7번째 걸음 숫자 표시는 유지하며 HUD 기능 변경 제안은 아니다.

## 7행성 구분

| 행성 | 외피 식별 언어 |
|---|---|
| moss | 녹색 이끼 쿠션, 따뜻한 회색 암반 |
| hollow | 보라회색, 정상부 아래 크게 열린 빈 섹터 |
| carved | 황토 석재, 깊은 수평 홈·층리 |
| frost | 차가운 청회색, 눈·서리 패치, 식생 없음 |
| joinery | 바랜 적갈 목재, 노출 장부·쐐기 |
| crumble | 저채도 회갈색, 깨진 코너와 큰 하부 파편 |
| altar | 절제된 황금빛 회색, 후면 독립 선돌·방사 기단 |

A/C frost 썸네일의 일부 벽에는 생성기가 녹황색 흔적을 남겼다. 이는 채택 대상이 아니며 frost의 MossMask는 외피·타일·벽 모두 0으로 고정한다. B altar 썸네일의 부채꼴 후면 부조와 임의 챕터 부제는 생성 변형이며 채택하지 않는다. 단순 독립 선돌로 치환하고 챕터 이름은 `chapters.json`을 따른다. 특정 종교 건축·상징 복제는 허용하지 않는다.

## 성능 영향과 2단계 조건

표의 tris는 외피와 외곽 장식의 제작 예산 추정이며 실측이 아니다. A는 큰 단면 몇 장으로 효율적이고, B는 반복 블록의 숨은 면 제거와 병합이 필요하다. C는 곡선 분할 수를 늘리면 가장 무거워지므로 뿌리 단면 4–6각·긴 세그먼트로 제한한다. D는 방사 조각 16–24개와 적은 선돌로 제한하고 원통 세분화를 늘리지 않는다.

공통으로 외피·장식은 4k tris 미만을 상한으로 삼고 기존 외피를 **교체**한다. 전체 보드 50k tris 이하와 현재 동일 스테이지 총량 이하를 동시에 만족해야 한다. 현재 외피 실측값이 이 예산보다 작으면 새 예산도 낮춘다. 기존 20,202 tris 조립 예시를 50스테이지 성능 보장으로 해석하지 않는다.

공유 아틀라스, 전체 6재질 이하, 불투명 서리, 버텍스 색·큰 면 명도 차이로 단면 음영을 표현한다. 신규 실시간 그림자·투명 뿌리·볼류메트릭·추가 고유 텍스처·애니메이션 파편은 쓰지 않는다. 삼각형 감소만으로 FPS가 개선된다고 주장하지 않으며 50번 스테이지의 draw call·GPU/CPU 비용은 채택 후 WebGL에서 전후 측정한다.
