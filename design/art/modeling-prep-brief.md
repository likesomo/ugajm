# 모델링 준비: 정면·후면·측면 도면, 질감, 셰이더 → Blender 3D 모델링 (2026-11-10)

## 사용자 지시
"해당 질감을 살릴 수 있도록 앞, 뒤, 옆, 질감, 쉐이더를 사용해서 구성을 진행하세요. 이후 블렌더를 통해 3D 모델링을 진행하세요."

## 기준
- 승인된 자연석 r2 시안: `concepts/themes/stage-resources-2026-11-10/r2/`. 두 가지 수정을 반영한 최신본을 쓴다.
  - 세쌍둥이는 눈 없는 후드다.
  - 판석은 질감 대비를 낮춘다.
- 행성별 석질은 다음과 같다.

| 행성 | 석질 |
|---|---|
| moss | 화강암 + 이끼 |
| hollow | 현무암·부석 |
| carved | 붉은 사암 |
| frost | 대리석·석영 |
| joinery | 점판암 + 목재 |
| crumble | 석회암·트래버틴 |
| altar | 사르센 사암 |

- 판 문법은 R2 A다(직사각 연석 + 지각).
- 게임 조건:
  - 1칸 = 1m
  - 카메라는 직교, pitch 50, yaw 0
  - WebGL 예산: 보드 전체 50k tris 이하, 드로우콜은 현행 이하, 머티리얼 6개 이하
  - 공유 아틀라스를 쓴다.

## 1단계: 에셋 도면(turnaround) 시트
에셋마다 한 장(1920×1080 이상)에 다음을 같은 축척으로 나란히 그린다. GPT 이미지와 직접 작도를 섞어도 된다.

- 보기: 정면(Front), 후면(Back), 좌·우 측면(Side), 윗면(Top), 게임 카메라 3/4(pitch 50)
- 1m 격자와 치수(m): 폭, 깊이, 높이, 모따기, 홈 깊이
- 피벗 위치
- 칸 경계선
- 재질 콜아웃: 어느 면이 어떤 질감인지 표시한다(윗면 마모 반들, 옆면 거친 쪼갬, 이끼 위치, 물때 방향).

### 대상

**행성별 키트 (7행성 × 다음)**
- 바닥 판석: 변형 2개
- 연석: 직선 1m, 모서리 기둥
- 지각 덩어리: 2~3개
- 대표 소품: 2개
- 하나의 행성 키트 시트에 모아도 된다.

**공용 기믹**
- 형태는 공용이고 재질만 행성별로 바꾼다.
- 대상:
  - 벽 블록
  - 숫자 문
  - 석상 수 문 Q
  - 문 A/B/C (열림·닫힘)
  - 발판 a/b/c
  - 구덩이 + 다리
  - 얼음
  - 금 간 바닥
  - 레버 (두 상태)
  - 뒤집힘 벽 R/r
  - 진흙
  - 출발점, 출구
  - KEEP 선돌

**세쌍둥이 말**
- 얼굴 없는 후드, 0.88m, 스카프 3색.
- 정면·후면·측면 도면만 만든다. 모델 교체는 이번 범위가 아니다. 기존 메시와 비교만 한다.

## 2단계: 질감(Texture) 시트
행성 석질마다 다음을 만든다.

1. **재질 견본**: 1024×1024 정사각, 타일링 가능하게 만든다.
   - Albedo(색)
   - 3단계 질감 설명 레이어:
     - 큰 형태: 블록 비율, 모서리 마모, 박리
     - 중간: 정 자국, 층리, 결 균열, 풍화 구멍, 물때, 지의류
     - 미세: 광물 입자, 러프니스 차이
2. **맵 계획**: 각 맵을 무엇으로 만드는지 적는다.
   - Normal: Blender 하이폴리에서 베이크
   - AO: 베이크
   - Roughness: 마스크
   - Edge wear: curvature
   - Moss와 frost: 월드 업 방향 + 버텍스 컬러
3. **판석용 저대비 버전**: 게임 가독성용이다.
   - 중앙 명도 변화 ±8% 이내
   - 결은 가장자리에 둔다
4. **목재·청동·이끼·얼음 공용 견본**: 각각 1장씩 만든다.

## 3단계: 셰이더 설계 (Unity URP, WebGL)

### 문서
`design/art/stone-shader.md`에 다음을 적는다.

- **레이어 구성**:
  1. 공유 색 아틀라스(AO 합성)
  2. 디테일 노멀(아틀라스)
  3. 블록별 색·밝기 변주(버텍스 컬러 또는 오브젝트 ID 해시, 반복 숨김)
  4. 엣지 마모 하이라이트(베이크 curvature를 버텍스 컬러나 채널에 저장)
  5. 이끼·서리 마스크(월드 업 dot + 마스크 채널, 행성별 강도. frost 서리는 이끼 대신)
  6. 물때 세로 그라디언트
  7. 행성 키 라이트·앰비언트 그라디언트 대응
  8. 게임 가독성: 판석 중앙 대비 제한, 줄눈 어둡게
- **행성별 파라미터 표**: ChapterPreset의 materialOverrides나 MaterialPropertyBlock으로 제어한다.
- **예산**:
  - 텍스처 샘플은 4개 이하다.
  - 기존 `RuinsSurface` 셰이더를 확장할지, URP Lit SimpleLit 기반 커스텀 셰이더로 갈지 비교하고 결정한다.
  - WebGL에서 컴파일과 변형 수를 확인한다.

### 프로토타입
- Blender 셰이더 노드로 같은 레이어 구성을 만들어 재질 견본 구(sphere)와 블록에 적용하고 렌더한다(7행성).
- Unity에서도 같은 견본 블록 1개를 행성별로 렌더해 Blender와 나란히 비교한다.

## 4단계: Blender 3D 모델링 (도면·질감·셰이더 승인 후)
- 1~3단계 결과를 코디네이터가 사용자에게 보여 주고 승인받는다. **승인 전에는 4단계를 시작하지 않는다.**
- 승인 후 Blender MCP로 모델링한다.
  - 열린 Blender는 판 A 석재 패스 워커와 공유한다. 그 워커가 끝난 뒤 사용한다.
  - 순서:
    1. 도면대로 하이폴리를 만든다.
    2. 저폴리로 만든다.
    3. 노멀·AO·curvature를 베이크한다.
    4. 공유 아틀라스로 모은다.
    5. FBX를 내보낸다.
    6. Unity 프리팹과 ChapterPreset에 연결한다. 기존 GUID는 유지한다.
- 행성 순서는 moss(판 A 결과와 정합) → carved → frost → hollow → joinery → crumble → altar다.
