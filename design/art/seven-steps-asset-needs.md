# 일곱 걸음 — 필요 에셋 목록 (Unity)

> 기준: `design/gdd/seven-steps-concept.md`, HTML 프로토타입 `prototypes/seven-steps/`.
> 시점은 미정. 1순위 3D 쿼터뷰 로우폴리, 2순위 2D 탑다운. 무료 에셋 조사 결과는 `seven-steps-asset-research.md`.
> 라이선스 우선순위: CC0 > Unity Asset Store 무료(Standard EULA) > CC-BY(크레딧 표기 필요). 상업적 이용·WebGL 배포 가능해야 함.

## 우선순위 표기
- **P0**: 없으면 게임이 안 됨 (잼 첫날 필요)
- **P1**: 출품 품질에 필요
- **P2**: 시간이 남으면

## 1. 환경 / 타일 (그리드 1칸 = 1유닛)
| 항목 | 게임 내 역할 | 우선 | 비고 |
|---|---|---|---|
| 바닥 타일 | 기본 칸 | P0 | 모듈형, 체크무늬나 변형 2~3종이면 좋음 |
| 벽 블록 | 막힌 칸 | P0 | 바닥과 같은 키트 |
| 구덩이 | 낙하 칸, 다리로 메워짐 | P0 | 바닥 없는 칸 + 가장자리 장식 |
| 얼음 바닥 | 미끄러짐 | P0 | 바닥 타일 + 반투명 하늘색 머티리얼로 대체 가능 |
| 금 간 바닥 | 한 번 지나가면 무너짐 | P1 | 금 간 텍스처 또는 조각난 타일 메시 |
| 발판 (a~c) | 석상이 누르는 스위치 | P0 | 색상 3종 구분 필요 |
| 문 (A~C) | 발판과 연결, 열림/닫힘 | P0 | 창살·석문, 열림 애니메이션 또는 내려가는 연출 |
| 숫자 문 (1~7) | N번째 걸음에만 통과 | P0 | 아치/기둥 + 숫자 (TextMeshPro로 숫자 표시) |
| 출구 | 7번째 걸음으로 도착 | P0 | 포털·제단·문 |
| 출발점 표시 | 현재/원래 출발점 (SWITCH) | P1 | 바닥 마커·깃발 |
| 장식 소품 | 분위기 | P2 | 기둥, 횃불, 덩굴, 돌무더기 |
