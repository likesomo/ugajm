- WebGL/mobile sky uses `RuinsSkyLow.shader`: opaque interpolated vertex color, no texture fetch, normal transforms, SH/additional lights, shadow coordinates/samples or fog. CPU-generated stars and nebula remain unchanged in geometry. Desktop retains the existing sky material.
- All seven Lighting presets disable realtime shadows on all three lights. Mobile_RPAsset disables HDR; the WebGL sky sets its parent camera allowHDR=false. Existing actor identity/foot rings ground the characters, so an additional transparent blob-shadow layer was not added.

Environment surfaces sample a shared original 256x256 weather map: R=stone wear/joints, G=low-frequency patina, B=wood grain. Frost uses zero moss; timber uses grain without green moss.

## WebGL measurement method

The baseline WebGL player is preserved in ignored `Builds/ArtPerfBefore`, and the final player is in `Builds/WebGL`. Both use the same opt-in `artperf=1` Unity sampler and the same single visible Orca browser pane: viewport 1280x800, game canvas 1280x720, scale 1, Mobile_RPAsset render scale 0.8, RTX 3060 / ANGLE D3D11. URLs use level 1, 29, 50 and replay R in both players. Each page warms up for 10 seconds, then records Unity frame intervals for 10 seconds; only one player is open, and this task's Unity builds/native players are stopped during each retained measurement (other workloads on the shared machine are not controlled). The sampler does not run in normal gameplay.

These are local end-to-end browser observations, not GPU-only timings or a mobile performance guarantee. One short sample per scene does not establish statistical significance, and browser scheduling/timer quantization can limit the measured frame rate. Tables and raw console JSON follow below.
