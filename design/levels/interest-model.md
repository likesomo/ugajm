# 흥미도 모델 (v0 가설)

스테이지마다 난이도 D와 흥미도 I를 숫자로 매겨 곡선으로 본다. 목표는 **D는 톱니 모양으로 오르고, I는 기준선 아래로 내려가지 않는 것**이다.
지금의 가중치는 가설이다. 사람 플레이테스트 기록으로 보정한다(아래 "보정 계획").

- 계산: `prototypes/seven-steps/tools/level-metrics.mjs` (규칙은 `src/core.js`를 그대로 씀)
- 판단 지표 입력: `design/levels/judgement.json`
- 결과: `design/levels/interest-curve.html`(커밋), `reports/level-metrics.json`(커밋 안 함)
- 실행: `export PATH="/c/Program Files/nodejs:$PATH"; node prototypes/seven-steps/tools/level-metrics.mjs`

모든 값은 0~1로 맞춘다. 정규화는 **고정 척도**를 쓴다(현재 스테이지들의 최솟값·최댓값이 아님). 그래야 스테이지를 더하거나 빼도 기존 스테이지 값이 변하지 않는다.

## 1. 난이도 D (자동)

솔버가 스테이지의 **실제 몸 제한**으로 상태 그래프 전체를 탐색해서 구한다(`explore()`).

| 항목 | 뜻 | 정규화 | 가중치 |
|---|---|---|---|
| bodies | 최소 몸 수 (`minBodies`) | (b−1)/6 | 0.25 |
| moves | 최소 몸 해의 행동 수(이동+KEEP/SWITCH) | log(m/7) / log(50/7) | 0.15 |
| search | 가장 짧은 해 길이보다 얕은 곳의 상태 수 = 답을 찾기 전에 볼 수 있는 경우의 수 | log10(n) / 5 | 0.25 |
| rarity | 해 길이만큼 아무렇게나 움직였을 때 이길 확률의 −log10 (= log10(같은 길이의 모든 행동열 / 이기는 행동열)) | ÷12 | 0.25 |
| traps | 새 몸이 깨어나는 순간(KEEP·SWITCH·낙하 직후) 중 더 이상 이길 수 없는 상태의 비율 | 그대로 | 0.10 |

`D = Σ 가중치 × 항목`

- 기획서가 말한 "해의 개수(적을수록 어려움)"는 rarity로 바꿨다. 해의 개수만 세면 1스테이지(일자 복도, 해 1개)가 가장 어렵게 나와서, 전체 경우의 수 대비 비율로 본다.
- traps는 12개 중 10개가 0.7~1.0이라 변별력이 낮아 가중치를 작게 뒀다(아무 데서나 SWITCH하면 대부분 막히는 게임 구조 때문).
- **한계**: 자동 D는 "생각의 크기"를 못 본다. 상태 수가 63개뿐인 7스테이지(홀짝)도 실제로는 어렵다. 이 부분은 깨달음 A와 플레이테스트 보정으로 메운다.

## 2. 기믹 태그

새로움·피로를 계산하는 단위. 대부분 자동으로 붙고, 솔버가 못 보는 것은 `judgement.json`의 `tagsAdd`로 붙인다.

| 태그 | 붙는 조건 |
|---|---|
| 7걸음 `walk7` | 모든 스테이지 (기본, 겹침 계산에서 제외) |
| 돌아가기 `detour` | 최소 해에 바로 되돌아가는 걸음(↑↓ 등)이 있음 = 걸음 수를 맞추려고 일부러 낭비 |
| KEEP 석상 `keep`, 석상 여러 개 `multiStatue` | 최소 해에서 KEEP 1번 이상 / 2번 이상 |
| SWITCH `switch` | SWITCH 없이 풀 수 없음 (솔버의 `SWITCH필수`) |
| 발판·문 `plate`, 구덩이 `pit`, 얼음 `ice`, 금 간 바닥 `cracked`, 숫자 문 `gate` | 맵에 그 타일이 있음 |
| 몸 다리 `bridge`, 봉인 다리 `seal` | 최소 해에서 구덩이 다리 / 금 간 바닥 봉인 이벤트가 일어남 |
| 판단 태그 | `parity`(홀짝), `statueStopper`(석상을 얼음 멈춤벽으로), `switchBack`(옮긴 출발점에서 되돌아오기) 등 |

## 3. 새로움 N (자동 + 판단)

```
N = 0.6 × min(1, 처음 나온 태그 수 / 2) + 0.4 × 0.4^(같은 태그 조합이 앞에서 나온 횟수) + nAdj
```
- 처음 보는 태그가 2개면 앞 항이 최대. 같은 조합이 반복될수록 뒷 항이 0.4, 0.16…으로 줄어든다.
- `nAdj`(−0.3~+0.3)는 자동 계산이 놓친 새로움을 사람이 보정할 때만 쓴다. 지금은 모두 0.

## 4. 깨달음 A (판단)

`judgement.json`에 스테이지마다 0~1과 근거 한 줄을 적는다.

| 값 | 기준 |
|---|---|
| 0.2 | 규칙 확인 |
| 0.4 | 작은 발견 |
| 0.6 | 생각을 바꾸는 발견 (예: SWITCH가 꼭 필요함, 석상이 발판을 눌러 줌) |
| 0.8 | "아하!" 소리가 날 만한 발견 (예: 얼음으로 홀짝을 바꿈) |

같은 발견을 두 번째로 쓰면 낮춘다(예: 10스테이지 = 3스테이지 ×2 → 0.3).

## 5. 적정 도전 C (자동)

플레이어의 현재 숙련도를 지금까지 깬 스테이지 난이도의 지수이동평균으로 둔다.
```
숙련도_k = 숙련도_{k−1} + 0.5 × (D_{k−1} − 숙련도_{k−1}),  숙련도_1 = 0
목표 D  = 숙련도 + 0.1 − (새 태그가 있으면 0.15)
C = exp(−((D − 목표 D) / 0.2)²)
```
- 숙련도보다 약간 어려울 때 1, 너무 쉽거나 어려우면 0으로 떨어지는 종 모양.
- 새 요소를 소개하는 스테이지는 목표가 0.15 낮다. 소개 스테이지는 쉬워야 한다는 뜻이고, 이것이 난이도 톱니를 만든다.

## 6. 피로 F (자동)

```
겹침 = 0.5 × J(직전) + 0.3 × J(2개 전) + 0.2 × J(3개 전)      (J = 기본 태그를 뺀 태그 집합의 자카드 유사도)
급상승 = 2 × max(0, D − D_직전 − 0.2)
F = (새 태그가 있으면 0.4, 없으면 1) × 겹침 + 급상승
```
- 새 것이 하나라도 있으면 겹침의 피로를 40%만 매긴다.
- 직전보다 D가 0.2 넘게 뛰면 그만큼 피로를 더한다(좌절).

## 7. 흥미도 I

```
I = 0.3 × N + 0.3 × A + 0.4 × C − 0.4 × F
```
- 기준선: **0.35**
- **흥미도 하락 구간**(곡선의 붉은 띠): I < 기준선 + 0.05, 또는 직전보다 I가 0.15 이상 떨어짐
- **새 기믹 투입 지점**(곡선의 붉은 삼각형): I < 기준선, 또는 같은 기믹 조합(새 태그 없이 직전과 자카드 ≥ 0.5)이 3스테이지 넘게 이어짐. 1스테이지는 제외
- 새 기믹은 "소개 → 응용 → 기존 기믹과 결합(반전)" 3스테이지로 넣는다.

## 8. 상수 한곳에

모든 상수는 `level-metrics.mjs` 맨 위 `M` 객체에 있다. 값을 바꾸면 이 문서도 같이 고친다.

| 상수 | 값 | 의미 |
|---|---|---|
| `dWeights` | bodies .25, moves .15, search .25, rarity .25, traps .10 | D 가중치 |
| `scale` | bodiesMax 7, moves 7~50, searchMax 1e5, rarityMax 12 | 고정 정규화 척도 |
| `iWeights` | N .3, A .3, C .4, F .4 | I 가중치 |
| `baseline`, `nearMargin` | 0.35, 0.05 | 기준선, 경고 여유 |
| `skillRate`, `stretch`, `introDiscount`, `sigma` | 0.5, 0.1, 0.15, 0.2 | 적정 도전 |
| `spikeFree`, `streakLimit` | 0.2, 3 | 급상승 허용폭, 연속 허용 |

## 9. 보정 계획 (플레이테스트)

스테이지별로 걸린 시간, Undo 수, 재시작 수, 풀이 보기 사용, 중단 지점을 받는다(수집 기능은 리드를 통해 게임플레이/UI에 요청).
1. **D 보정**: 실측 난이도 = 정규화한 (시간, Undo+재시작, 풀이 보기)의 평균. 자동 D와의 순위 상관을 보고, 어긋나는 항목의 가중치를 고친다. 7스테이지처럼 자동 D가 과소평가하는 스테이지는 `judgement.json`에 D 보정 항목을 추가하는 것도 검토.
2. **I 보정**: 중단 지점 직전 스테이지의 I가 기준선 아래에 있어야 모델이 맞다. 아니면 F·C 가중치를 고친다.
3. 사람 판단 A는 플레이어가 "아!" 하고 말한 순간 기록이 있으면 그걸로 바꾼다.
