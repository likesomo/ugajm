## 만들면서 바꾼 것

- **뼈대 탐색 (`stage-search.mjs --base`)**: 석상 수 문이 들어간 조합(41, 42, 47, 48)과 7×7(49)은 판 전체를 무작위로 만들면 3만~4만 번에 후보가 0개였다. 손으로 그린 벽 뼈대(복도 둘레·기둥 방)를 고정하고 기믹 칸만 무작위로 놓으면 4천 번에 수~수십 개가 나왔다. 50 원형 제단도 고리 모양 뼈대에서 찾았다. Git Bash가 인자의 `/`를 경로로 바꾸므로 뼈대 행은 쉼표로 나눈다
- **41 선돌 아닌 흔적**, **42 무너지는 계산**: 봉인(굳은 바닥)과 다리는 석상이 아니라 석상 수 문이 열리지 않는다는 점을 쓴다. 문은 끝까지 닫혀 있고 다른 길로 돌아간다. "흔적으로 문을 연다"는 판은 몸 3개에서 찾지 못했다
- **48 길이 된 형제들**: 계획의 0 문을 함께 넣은 판은 0개(석상이 없으면 0 문은 늘 열려 장식이 됨). 봉인 + 다리로 두 형제가 모두 길이 되는 판으로 만들었다
- **흥미도 도구 수정 (`level-metrics.mjs`)**: 레버(L)와 진흙(m) 칸에 기믹 태그가 붙지 않던 것을 고쳤다. 진흙 소개(43)가 "새 기믹 없음"으로 계산되어 0.23으로 나오던 것이 0.41이 됐다. 레버 스테이지들의 값도 조금 바뀌어 묶음 1~4 곡선과 지금 17스테이지 곡선(`interest-curve.html`)을 다시 그렸다. 지금 17스테이지의 값 변화는 0.01 안쪽이다(레버 태그를 판단 태그로 이미 붙이고 있었음)
