## 발견한 문제 (화면별)

### 공통: 버튼과 숫자 상자 테두리
- 이중 테두리 안쪽의 가로선이 글자를 관통한다. 행성 번호 1~7, 챕터 카드 버튼, HUD 하단 버튼에서 보인다.
- 9-slice 스프라이트 border가 없거나 잘못되어 장식선이 늘어나 텍스트 영역으로 들어온 것으로 보인다.
- 수정 방향:
  - 스프라이트 border를 바로잡는다.
  - 텍스트 영역에 padding을 둔다(장식선 안쪽 최소 8px).
  - 장식선이 텍스트 뒤를 지나가지 않게 한다.
  - 스프라이트 자체가 문제면 코디네이터를 거쳐 Codex에 요청한다.

### 행성 선택 (en-map)
- 북두칠성 연결선이 행성 이름과 번호 상자를 관통한다(1→2, 3→4, 4→5).
  - 선은 상자 가장자리에서 끊는다.
  - 텍스트 뒤에는 배경 판(pill)을 둔다.
  - 선은 굵기 2px 이상, 대비가 충분한 색으로 한다.
- 별 개수("★ 0/21")가 자기 행성에서 떨어져 다른 행성 위에 놓인다.
  - 예: 1번의 별 개수가 2번 바로 위에 있다.
  - 이름·번호·별 개수를 한 카드로 묶고, 카드끼리 겹치지 않게 배치한다.
- "All stars: 0/150"이 3번의 별 개수와 붙어 있다. 하단 정보 띠로 분리한다.
- 배경 보드와 선돌이 노드 뒤에서 경쟁한다. 배경을 더 어둡게, 흐리게, 작게 한다.
- 7번만 0/24다(스테이지 8개). 의도된 값이면 그대로 두고, 아니면 확인한다.

### 로딩 (webgl-loading)
- 북두칠성 진행 표시와 "5/7"이 화면 대비 너무 작고 빈 공간이 많다.
  - 진행 표시를 화면 폭 40~50%로 키운다.
  - 별 크기와 선 굵기를 키운다.
  - 진행 숫자를 크게 한다.
  - 진행 중인 별에 빛 연출을 준다.
- WebGL 페이지에서 캔버스가 작고 주변이 흰 여백이다.
  - WebGL 템플릿을 창 크기 맞춤(비율 유지)으로 바꾼다.
  - 바깥 배경은 게임과 같은 짙은 남색으로 한다.

### 챕터 진입 카드 (ko-chapter)
- 행성 이름 "서리 위성"이 선돌과 보드 위에 바로 놓여 읽기 어렵다. 텍스트 뒤에 판을 두거나 배경을 어둡게 한다.
- 7개 행성 버튼의 글자가 작고, 버튼 안 장식선이 글자를 가른다(공통 문제).
- 설명 문장도 배경 판 없이 보드 위에 있다.

### 결과 (flow14-result)
- 결과 패널이 HUD 위에 덮이는데, HUD의 다음 요소가 패널 가장자리에 잘려 보인다.
  - 왼쪽 힌트 "멀리 넘긴 출발점에서 다시"
  - 위쪽 북두칠성 숫자
  - 아래쪽 조작 안내
  - 수정: 결과가 뜨면 HUD를 어둡게 덮거나 숨긴다.
- 별 조건 문구가 작고 줄바꿈이 어색하다("형제 / 3명으로").
- 버튼 글자가 작다.

### 인게임 HUD (level22)
- 스테이지 제목 "22 미끄러운 첫걸음" 뒤로 원경 빙산이 지나간다.
- 왼쪽 힌트 문장이 얼음 기둥과 보드 영역에 겹친다.
  - 텍스트에 반투명 배경 판을 두거나 안전 영역을 둔다.
  - 장식은 HUD 영역 밖으로 뺀다.
- 북두칠성 HUD에서 선이 번호 2, 3을 가린다.
- 오른쪽 위 세쌍둥이 상태 라벨("사용 중", "남음")이 작고 아이콘과 떨어져 있다.
- 조작 안내 한 줄("이동: 방향키…")이 아주 작고 대비가 낮다. 버튼 줄과도 붙어 있다.

## 해야 할 것
1. **레이아웃 규칙**을 `docs/architecture.md`(UI 절)나 `design/art/ui-theme.md`에 적는다. 아키텍트가 검토한다.
   - 텍스트 최소 크기: 1280×720 기준 본문 22px, 보조 18px.
   - 텍스트 대비: WCAG 4.5:1 이상.
   - 텍스트 뒤 배경 판 규칙.
   - 장식선은 텍스트 사각형을 지나지 않는다.
   - HUD 안전 영역과 보드 영역은 겹치지 않는다.
   - 모달이 뜨면 아래 UI를 덮는다.
2. **단정적 검증기**를 `SceneFlowValidator`에 추가한다. 이름 예: UiLayoutCheck, `scene-validate`와 빌드 전에 실행한다.
   - 대상: Title, StageSelect(ko/en), Loading, ChapterCard, HUD, Result, Settings.
   - 1280×720과 1920×1080에서 레이아웃을 계산한다. 다음을 위반하면 실패로 처리한다.
     - 보이는 텍스트 사각형끼리 겹침.
     - 텍스트 사각형과 선·Image 장식이 겹침(허용 목록 제외).
     - 텍스트가 부모 밖으로 넘침이나 잘림.
     - 최소 글자 크기 미만.
   - 가장 긴 문자열(ko/en, 23번 힌트 등)로도 검사한다.
3. 위 화면별 문제를 고친다.
   - 소유:
     - 행성 선택, 로딩, 챕터 카드, 설정, WebGL 템플릿: scene-flow.
     - HUD, 결과, 버튼 스킨: gameplay-ui.
   - 리드가 배분하고, 아키텍트가 리뷰한다.
4. 전후 캡처를 ko/en, 1280×720과 WebGL로 `reports/ui-layout/`에 남긴다. 리드가 코디네이터에게 경로를 보고한다.
5. 기존 테스트를 모두 통과시킨다: test, scene-validate, GlyphCheck, smoke(title·flow), smoke-webgl.
