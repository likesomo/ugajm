## 승인된 결정 (2026-11-11)
- **상시 HUD**: 메뉴·작은 제목·되돌리기·재시작·형제 점 3개만. 방향 버튼·조작키 줄·안내문은 첫 회 튜토리얼에만(scene-flow 저장).
- **보드**: 화면 중앙·크게. 프레이밍 ortho 4.65, 중심 (0,-0.75,0) 제안 반영(8×6 셀 약 77px). `HudView.BoardFrame`을 줄어든 HUD에 맞춰 키운다.
- **선택 UI v3**: Choose일 때만 — 보드 30% 암부 + 형제 선택 링 + 보드 밖 여백의 두 카드(그림·이름 남기기 KEEP/넘기기 SWITCH·K/X 배지·결과 한 줄, 다음 형제 머플러색 테두리, 첫 3회 확정까지 두 설명 항상 표시) + 호버/포커스한 쪽만 보드 고스트(KEEP: 선돌+출발점 형제+점선, SWITCH: 형제+매듭) + 0.5초 이하 확정 연출. Z는 선택 전으로.
- **발치 별 7개**: 숫자 없음, 1280×720 실제 보드에서 판독 확인. 6걸음 뒤 마지막 빈 별 맥동. "걸음 숫자 표시" 설정(기본 꺼짐).
- **별 흔적 v2**: 단일 형제 점·직각선, KEEP 굳은 별자리+선돌 별, SWITCH 매듭, 7번째 각성, Undo 시 소멸, 행성별 변주(`StarTrailPreset`). 형제는 실제 후드 모델.
- **검증**: UiLayoutCheck, GlyphCheck, EditMode 전체, WebGL 빌드 + smoke-webgl, 실제 플레이 캡처 5종(평소/6걸음/선택/KEEP 후/SWITCH 후)을 7lucky 통합 후 보고.

## 지시 요약
1. 평소 HUD: 메뉴 1개(설정·스테이지·풀이 보기는 메뉴 안), 되돌리기, 재시작, 작은 제목.
2. 조작키 안내: 첫 스테이지와 새 조작이 처음 필요할 때 1회만 보이고 숨김.
3. 걸음 수·7을 숫자로 띄우지 않음. 별 흔적 + 형제 발치의 별 7개 고리로 남은 걸음을 읽고, 6걸음 뒤 7번째 별이 맥동. 하늘 북두칠성 HUD도 숫자 없음. 접근성 옵션 "걸음 숫자 표시"(기본 꺼짐).
4. KEEP/SWITCH: 형제 위치에 고정된 두 갈래 선택(선돌 아이콘 / 바통·매듭 아이콘), 다음 형제 고스트 미리보기, 다음 형제 머플러 색 테두리, 처음 2~3회만 설명.
5. 형제 슬롯은 머플러 색 점 3개. 힌트·이야기 상시 표시 없음. 결과 화면은 별, 별자리, 다음 버튼만.

## 이미 있는 것과의 관계
- **ui-layout-fix**: 겹침 수정은 끝나 7lucky에 있다(HUD/결과 오류 0). HUD 재배치는 시안 승인 뒤에만.
- **보드 프레임**: HUD가 줄면 `HudView.BoardFrame`(648×398)이 커질 수 있다. Codex 제안 8×6 셀 77px(현재 64.9px, padding .5)이 가능해지는지 같이 본다(`BoardView.Fit`은 프레임을 따름).
  - architect 계산(2026-11-10, 8×6, pitch 50): 77px에는 1280×720 기준 틀이 padding .5면 693×472, .7이면 724×496 이상. 안전 영역 24씩 빼면 높이 672가 남으니 위 HUD 띠 + 아래 버튼 띠를 합쳐 약 200px 안(지금 위 222, 아래 100)이면 된다. 12×5는 같은 77px에 1001×413이 필요해 가로가 결속 축 — 옆 열을 줄이지 않으면 77px은 8×6 같은 판만.
- **QA 하네스**: 텍스트 하네스라 영향 없음. 사람 플레이테스트 안내(`playtest-guide.md`)의 조작·화면 설명은 고쳐야 함.
- **이야기 구조**: 결과·HUD에 글을 상시 두지 않는다는 지시와 story-integration의 순간 문구(시도당 1회)·결과 문구를 맞춰야 함 → 스토리 디렉터에 알림.
- **플레이테스트 1차(금요일)**: 큰 HUD 변경이라, 최종 빌드 전에 승인·검증이 끝나지 않으면 현재 HUD로 진행하고 다음 빌드에 넣는다(사용자 확인 필요).
